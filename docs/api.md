# API notes

Interactive schema: `http://localhost:8000/docs` (generated by FastAPI).

Auth: `POST /api/v1/auth/login` → `Authorization: Bearer <token>`.

WebSocket: `ws://localhost:8000/api/v1/ws/transactions?token=<jwt>`.

Decisions APPROVE / REVIEW / BLOCK use `THRESHOLD_REVIEW` / `THRESHOLD_BLOCK` on the combined 0–100 risk score. Those env vars are configurable experiments, not industry-standard cutoffs. `ml_probability` is calibrated P(fraud) when the calibrator is loaded; `ml_score` is a risk score, not a displayed percent.

Responses include `X-Request-ID` (echoed from the request or generated).

Investigations: `POST /api/v1/investigations/{id}/run` accepts an investigation id or a transaction id. `GET /api/v1/investigations/{id}/trace` returns the persisted tool trace. See `docs/llm-investigation-agent.md`.

Graph: `GET /api/v1/graph/metrics`, `/snapshot`, `/clusters`, `/status`. `POST /api/v1/graph/reset` (ADMIN, non-production). There is no Cypher endpoint. See `docs/graph-backend.md`.

Feedback / monitoring: `POST/GET /api/v1/feedback`, `GET /api/v1/ml/drift`, `GET /api/v1/ml/model-status`, `POST /api/v1/simulation/evaluate`. See `docs/feedback-and-model-monitoring.md`.

IEEE-CIS offline evaluation: `GET /api/v1/ml/ieee-evaluation` (also nested under `GET /api/v1/ml/offline-evaluation` as `ieee`). Labeled **OFFLINE PUBLIC DATASET EVALUATION**. Not live scoring. See `docs/ieee-cis-evaluation.md`.
